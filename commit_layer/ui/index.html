02 Security Invariants
RULE 01
Deterministic Floor is Inviolable
AI models and payee lookups can only escalate risk. The deterministic policy is the absolute bottom floor.
RULE 02
Committed ≠ Succeeded
Dispatching a request is not remote success. Out-of-band observers independently qualify the outcome state.
RULE 03
Undo Requires Verified Inverse
Undo is only enabled when the outcome was confirmed as OBSERVED_SUCCESS and a legitimate inverse function exists.
